# Project Dustbin (Brain Classification Archive)

This directory archives old training runs, weights, visuals, and logs before the September 19 Kaggle 42-class zero-leakage training run was deployed.

### Contents:
- `checkpoints/`: Old initial model checkpoint (`brain_best_model.pth` from Sep 18).
- `visuals/`: Old 39-class training curves, metrics, confusion matrix, and prediction samples.
- `public_visuals/`: Backup of previous public assets served to the frontend.
- `kaggle_training_scripts.zip`: Previous training runner script bundle.

*Note: This folder is excluded from version control via `.gitignore`.*
